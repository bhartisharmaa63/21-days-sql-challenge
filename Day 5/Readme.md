## Day 05 - Aggregate functions and data summarization

Practiced:
- Counting total records using COUNT()
- Calculating averages with AVG()
- Identifying minimum and maximum using MIN() and MAX(), respectively
- Summarizing numeric data accurately using SUM()
- Rounding off values using ROUND()

**Challenge:** Calculate the total number of patients admitted, total patients refused, and the average patient satisfaction across all services and weeks. Round the average satisfaction to 2 decimal places.
